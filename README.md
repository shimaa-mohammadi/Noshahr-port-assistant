# 🚢 Noshahr Port Assistant — دستیار دیجیتال بندر نوشهر

ربات تلگرام فارسی برای رانندگان، کارگزاران کشتی، صیادان، گردشگران و کارکنان سازمانی —
با وضعیت زنده دریا (موج، باد، دمای آب)، پیش‌بینی ۴۸ ساعته، هوای مسیر تهران←نوشهر،
دیده‌بان شناورها (AIS)، هشدارهای خودکار و اطلاعیه‌های بندر.

---

## ✨ امکانات به تفکیک نقش کاربر

ربات در `/start` نوع کاربر را با **دکمه‌های شیشه‌ای (Inline)** می‌پرسد:

| نقش | سرویس‌های اختصاصی |
|---|---|
| 🚛 راننده | هوای مسیر تهران←کندوان←چالوس←نوشهر، راهنمای مدارک بار |
| 🚢 کارگزار کشتی | دیده‌بان AIS شناورهای اطراف، پنجره هوایی عملیات ۱۲ ساعته، هشدار ورود شناور به محدوده بندر |
| 🎣 صیاد | وضعیت ایمنی قایق کوچک (سبز/زرد/قرمز)، هشدار موج خطرناک با آستانه دلخواه |
| 🏖 گردشگر | اطلاعات ساحل: دمای آب، موج، طلوع/غروب، وضعیت شنا |
| 🏢 سازمانی | دیده‌بان AIS، آمار تردد شناورهای ۲۴ ساعت اخیر |
| 👑 مدیر (اختیاری) | ارسال اطلاعیه به همه کاربران، مدیریت اطلاعیه‌ها، آمار کاربران |

داده‌ها: **Open-Meteo** (رایگان، بدون کلید) + **aisstream.io** (رایگان با ثبت‌نام).

## 🛠 راه‌اندازی قدم‌به‌قدم

### قدم ۱ — ساخت ربات در تلگرام
1. در تلگرام به **@BotFather** پیام بدهید
2. دستور `/newbot` → اسم و یوزرنیم انتخاب کنید
3. توکن (شبیه `123456:ABC-DEF...`) را کپی کنید

### قدم ۲ — کلید رایگان AIS (اختیاری ولی پیشنهادی)
1. در **[aisstream.io](https://www.aisstream.io)** ثبت‌نام کنید (رایگان)
2. کلید API را از پنل کپی کنید

### قدم ۳ — چت‌آیدی مدیر (اختیاری)
- به **@userinfobot** پیام بدهید تا `chat_id` عددی خودتان را بگیرید
- آن را در `config.py` → `ADMIN_CHAT_ID` بگذارید (برای دستور `/admin` و ارسال اطلاعیه)

### قدم ۴ — نصب و اجرا
```bash
cd noshahr_port_bot
pip install -r requirements.txt
```

توکن‌ها را در `config.py` بگذارید (یا با متغیر محیطی):
```bash
# لینوکس / مک
export BOT_TOKEN="123456:ABC-..."
export AIS_API_KEY="کلید-aisstream"
export ADMIN_CHAT_ID="12345678"
python bot.py
```
```powershell
# ویندوز پاورشل
$env:BOT_TOKEN="123456:ABC-..."
$env:AIS_API_KEY="کلید-aisstream"
$env:ADMIN_CHAT_ID="12345678"
python bot.py
```

پس از اتصال، پیام `ربات @YourBot آماده است ✅` را می‌بینید. تمام! 🎉

### ⚠️ نکته مهم برای ایران
تلگرام و aisstream از IP ایران ممکن است در دسترس نباشند. دو راه دارید:
- **بهترین راه:** اجرای ربات روی یک **VPS خارج از ایران** (هزینه ماهانه حدود ۳-۵ دلار)
- یا ست کردن پروکسی قبل از اجرا:
  ```bash
  export HTTPS_PROXY="http://127.0.0.1:PORT"   # پروکسی شما
  ```

## 📡 اتصال گیرنده محلی RTL-SDR (شناورهای واقعی نوشهر!)

پوشش AIS شبکه‌های جهانی در دریای خزر تقریباً **صفر** است. با یک گیرنده ارزان، خودتان منبع داده می‌شوید و شناورهای اطراف نوشهر (برد ۳۰-۶۰ کیلومتر) زنده در ربات ظاهر می‌شوند.

### لیست خرید
| قطعه | توضیح | قیمت تقریبی |
|---|---|---|
| دونگل **RTL-SDR** (RTL2832U + R820T2) | مدل RTL-SDR Blog V3/V4 یا generic | ۱-۲ میلیون تومان |
| آنتن تلسکوپی VHF یا دوقطبی ساده | تیون‌شده روی ~162MHz (باندهای دریایی) | ۳۰۰-۸۰۰ هزار تومان |
| پایه آنتن + کابل کواکسیال | هرچه بالاتر و نزدیک‌تر به ساحل، بهتر | متغیر |
| کابل USB بلند | برای رساندن دونگل به نزدیک آنتن | — |

### نحوه کار
```
آنتن ساحل نوشهر → دونگل RTL-SDR → rtl-ais (رمزگشا) → UDP پورت 10110 → این ربات 🚢
```
ربات **همیشه** روی UDP پورت `10110` (قابل تغییر در config: `NMEA_UDP_PORT`) به جملات NMEA گوش می‌دهد — چه کلید استریم جهانی داشته باشید چه نه.

### نصب رمزگشا (سمت دستگاهی که دونگل به آن وصل است)
**لینوکس / رزبری‌پای:**
```bash
sudo apt install rtl-ais        # اگر در مخزن نبود، از github.com/dgiardini/rtl-ais کامپایل کنید
rtl-ais -u 127.0.0.1 -p 10110   # ارسال NMEA به ربات (اگر ربات روی همین دستگاه است)
# اگر ربات روی دستگاه دیگری است: rtl-ais -u <IP-ربات> -p 10110
```
**ویندوز (WSL2):** Ubuntu را از Microsoft Store نصب کنید، دستورات بالا را داخل آن اجرا کنید
و USB را با `usbipd-win` به WSL پاس بدهید.

### تنظیم فرکانس
rtl-ais خودش روی هر دو کانال AIS دریایی (161.975 و 162.025 مگاهرتز) گوش می‌دهد.
اگر دستی تنظیم می‌کنید: فرکانس مرکزی 162.000MHz، نرخ نمونه 38.4k، دیمودولاسیون FM.

### نکته‌ها
- آنتن را **بیرون و مرتفع** نصب کنید؛ دید باز به دریا = برد بیشتر
- دریافت غیرفعال رادیو AIS مجاز و بدون نیاز به مجوز است
- اولین شناور که ظاهر شد، ربات خودش «⚓ وارد محدوده بندر شد» را اعلام می‌کند!

## 📣 اجرای دائمی (VPS)

```bash
# با systemd (لینوکس): فایل /etc/systemd/system/noshahrbot.service
[Unit]
Description=Noshahr Port Bot
After=network-online.target

[Service]
WorkingDirectory=/opt/noshahr_port_bot
Environment=BOT_TOKEN=...
Environment=AIS_API_KEY=...
Environment=ADMIN_CHAT_ID=...
ExecStart=/usr/bin/python3 bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```
سپس: `systemctl enable --now noshahrbot`

## ⚖️ نکات مسئولیت

- داده‌های AIS از **جریان عمومی جهانی** است (همان چیزی که سایت‌هایی مثل VesselFinder نشان می‌دهند)؛
  پوشش در سواحل جنوبی خزر ممکن است محدود باشد.
- سازمان بنادر مازندران **سیستم AIS رسمی خودش** را در بندر نوشهر دارد؛ برای نسخه رسمی/
  سازمانی، حتماً با اداره کل بنادر و دریانوردی مازندران هماهنگ کنید — هم برای داده بهتر، هم
  برای اعتبار رسمی.
- پیش‌بینی هوا جایگزین اعلان رسمی بندر نیست؛ در متن ربات هم آمده است.
- شماره‌های تماس در `config.py` نمونه‌اند و باید پیش از عرضه عمومی تکمیل شوند.
